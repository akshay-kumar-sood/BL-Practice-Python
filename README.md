### Python Regular Expression regex

# codes summary
* \d -> digit from 0-9
* \d+ -> digit 24 treat as 24 not 2 and 4
* \D -> non digit
* \w -> letters numbers underscore
* \W -> match special character space
* \s -> match space newline tab
* [] -> search in range [0-9] [a-z] [a-zA-Z]
* a* -> zero or more
* ? -> zero or one
* {} -> exact no of time repetition
* ^ -> start of string means search hello so in "hi hello" fails
* $ -> end of string
* | -> or operator
* \. -> represents actual dot
