### Python Regular Expression regex

# codes summary
* 1. \d -> digit from 0-9
* 2. \d+ -> digit 24 treat as 24 not 2 and 4
* 3. \D -> non digit
* 4. \w -> letters numbers underscore
* 5. \W -> match special character space
* 6. \s -> match space newline tab
* 7. [] -> search in range [0-9] [a-z] [a-zA-Z]
* 8. a* -> zero or more
* 9. ? -> zero or one
* 10. {} -> exact no of time repetition
* 11. ^ -> start of string means search hello so in "hi hello" fails
* 12. $ -> end of string
* 13. | -> or operator
* 14. \. -> represents actual dot
